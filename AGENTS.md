# Fake Review Detection — agent notes

## Commands (run from the repo root)
- Set `$env:PYTHONIOENCODING='utf-8'` before Python on PowerShell; Vietnamese console output otherwise breaks.
- Scripts are flat and use bare imports (`from config import ...`): run `python MaNGuon\<file>.py`, never `python -m MaNGuon.<file>`. `MaNGuon/config.py` is the only place paths/constants are declared — don't hardcode `..` paths.
- Full check: `python -m compileall -q MaNGuon` then `cmd /c ThuMucKhoiChay\3_Kiem_Tra_Toan_Ven.bat`; expect `TAT CA DEU DAT.`. There is no test suite. `CANH BAO: con buoc chua chay` from `run_all.py --check` means stale cache, not failure.
- `python MaNGuon\run_all.py` reruns only stale steps (fingerprints in `KetQuaChay/run_state.json`). Flags: `--check` (exit 1 = work pending), `--full`, `--no-network`, `--no-notebook`, `--check --full` to preview a full run. Step 5 (web) is deliberately excluded — start it separately.
- `python MaNGuon\api_server.py` serves both UI and API at `http://127.0.0.1:8000/`. Double-clicking `Web/index.html` only shows static tables; manual input and CSV upload need the server.

## Data / DB gotchas
- PostgreSQL runs in Docker on `127.0.0.1:5434`, container `fakereview_db`. Run `docker compose up -d` **inside `ThuMucChienKhai/`** so Compose picks up its `.env`. Never `docker compose down -v` — it wipes the volume.
- `ThuMucChienKhai/.env` holds the real password and is gitignored; only `.env.example` is committed. Never print or commit it. `MaNGuon/db.py` parses it with a hand-rolled KEY=VALUE reader (no python-dotenv) and overrides `config.py` defaults; all DB access goes through `db.py` + pg8000.
- `restore_db.py` defaults to scratch DB `fakereview_restore_check`; touching the real DB needs both `--database fakereview` and `--allow-production`. Restore drops and recreates the target DB.
- `DuLieuDemo/data_meta.js` and `data_reviews.js` are generated by `export_web_data.py` (`.js`, not `.json`, so `file://` `<script>` tags work) — never hand-edit. `DuLieuDeHoc/DuLieuTho/` is read-only raw data; `KetQuaChay/baseline_metrics_v1.json` is write-once.

## Domain quirks
- Dataset is English-only; Vietnamese input is translated to English before prediction via public services. Bot/boost/spam groups are inference rules, not ground-truth labels — don't report them as labeled data.
- `.bat` files in `ThuMucKhoiChay/` are intentionally accentless (`cmd.exe` byte parsing); don't add diacritics.
- Original dataset is OSF `https://osf.io/tyue9/` (Salminen et al., 2022, CC BY 4.0); Kaggle `mexwell/fake-reviews-dataset` is only a mirror. Local CSV matches OSF SHA-256 `ea03422988824bc917b5f7217e3867e27b597c647d5261adfae73cd7a85e1e1a`.
